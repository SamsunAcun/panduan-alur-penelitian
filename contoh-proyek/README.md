# Contoh proyek penelitian

Folder ini adalah template latihan tanpa data atau sumber penelitian nyata.

1. Isi [brief](01-BRIEF.md) dengan pertanyaan dan batas penelitian.
2. Catat sumber yang benar-benar diperoleh di [daftar sumber](03-DAFTAR-SUMBER.md).
3. Tulis argumen di [naskah](02-NASKAH.md) setelah sumber diperiksa.
4. Gunakan `git diff` untuk meninjau suntingan dan commit per tahap kerja.

Untuk penelitian sendiri, salin folder ini ke lokasi baru di luar repositori tutorial.

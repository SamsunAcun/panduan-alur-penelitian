# Contoh proyek penelitian

Folder ini adalah template latihan tanpa data atau sumber penelitian nyata.

1. Isi [brief](03-PERENCANAAN/BRIEF.md) dengan pertanyaan dan batas penelitian.
2. Simpan bahan awal di [folder sumber](01-SUMBER/README.md) dan catat sumber yang benar-benar diperoleh di [daftar referensi](07-REFERENSI/DAFTAR-SUMBER.md).
3. Isi [rencana kerja](03-PERENCANAAN/rencana.md), lalu tulis argumen di [naskah](02-NASKAH/draf.md) setelah sumber diperiksa.
4. Simpan berkas hasil ekspor di [folder keluaran](06-KELUARAN/README.md).
5. Gunakan `git diff` untuk meninjau suntingan dan commit per tahap kerja.

Untuk penelitian sendiri, salin folder ini ke lokasi baru di luar repositori tutorial.
